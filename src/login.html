Pengaturan Koneksi Google Apps Script

Hubungkan portal SiKoBaELah ke URL Web App Spreadsheet untuk sinkronisasi cloud realtime.

Salin URL ini setelah melakukan Deploy > New deployment > Web app (Who has access: Anyone) pada spreadsheet Anda.

Petunjuk Menjalankan Database Baru:

  1. Buka spreadsheet Anda di Google Drive.
  2. Buka Ekstensi > Apps Script lalu salin isi file src/db kode gs/Code.gs.
  3. Jalankan fungsi inisialisasiDatabase 1x untuk mengisi otomatis data 33 regulasi dan 7 modul aplikasi.
  4. Klik Deploy > New Deployment > Web app dan atur hak akses ke Anyone (Siapa saja).
  5. Tempelkan URL Web App tersebut ke kotak di atas lalu simpan.
